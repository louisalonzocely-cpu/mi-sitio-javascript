¿Qué son las variables?

Las variables son contenedores que almacenan datos. En JavaScript se declaran con let, const o var. 


            let nombre = "Juan";
            const edad = 20;
            var curso = "ADSO";

let: permite reasignar su valor.
const: su valor no puede cambiar después de declararlo.
var: forma antigua, se recomienda evitar su uso.

Tipos de datos

JavaScript maneja varios tipos de datos primitivos: 


        // String - Cadenas de texto
        let texto = "Hola mundo";

        // Number - Números (enteros y decimales)
        let entero = 10;
        let decimal = 9.5;

        // Boolean - Verdadero o falso
        let activo = true;

        // Undefined - Variable sin valor
        let sinValor;

        // Null - Valor vacío intencional
        let vacio = null;

        // Object - Objeto con propiedades
        let persona = {
            nombre: "Luis",
            edad: 22
        };

        // Array - Lista de valores
        let colores = ["rojo", "azul", "verde"];

Operadores

Los operadores permiten realizar operaciones sobre datos.

Operadores aritméticos


            let a = 10;
            let b = 3;

            console.log(a + b);  // 13 - Suma
            console.log(a - b);  // 7  - Resta
            console.log(a * b);  // 30 - Multiplicación
            console.log(a / b);  // 3.33 - División
            console.log(a % b);  // 1 - Residuo
            console.log(a ** b); // 1000 - Potencia

Operadores de comparación


            let x = 5;

            console.log(x == "5");   // true  - Igual (solo valor)
            console.log(x === "5");  // false - Igual estricto (valor y tipo)
            console.log(x != 3);     // true  - Diferente
            console.log(x > 3);      // true  - Mayor que
            console.log(x <= 10);    // true  - Menor o igual que

Operadores lógicos

let edad = 25;
            let tieneCertificado = true;

            console.log(edad >= 18 && tieneCertificado);  // true  - AND
            console.log(edad < 18 || tieneCertificado);   // true  - OR
            console.log(!(edad < 18));                    // true  - NOT

Funciones

Las funciones permiten agrupar código reutilizable. Se pueden declarar de dos formas principales:

Declaración de función


                function saludar(nombre) {
                return "Hola, " + nombre;
            }

            console.log(saludar("Juan"));

Expresión de función

const sumar = function(a, b) {
                return a + b;
            };

            console.log(sumar(4, 6));

Función flecha (ES6)

const multiplicar = (a, b) => a * b;
            console.log(multiplicar(3, 5));

Interacción con el navegador

JavaScript puede mostrar información al usuario mediante diferentes métodos del navegador. 

// Ventana emergente
            alert("¡Hola!");

            // Cuadro de entrada
            let nombre = prompt("¿Cuál es tu nombre?");

            // Mensaje en consola del navegador
            console.log("Nombre: " + nombre);

Resumen

Variables: let, const y var para almacenar datos.
Tipos: string, number, boolean, null, undefined, object, array.
Operadores: aritméticos, de comparación y lógicos.
Funciones: declaración, expresión y flecha.
Navegador: alert, prompt y console.log.
